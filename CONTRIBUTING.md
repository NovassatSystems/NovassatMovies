# Contribuindo com o NovassatMovies

Agradecemos seu interesse em contribuir para este projeto! Para mantermos uma base de código organizada e de fácil manutenção, siga as diretrizes abaixo.

## 🧾 Como contribuir

1. Fork este repositório
2. Crie uma branch com o nome da sua funcionalidade ou correção:
   ```bash
   git checkout -b minha-feature
   ```
3. Faça suas alterações com boas práticas e commits claros
4. Envie a branch para seu fork:
   ```bash
   git push origin minha-feature
   ```
5. Abra um Pull Request com uma breve descrição do que foi feito

---

## 💡 Boas práticas

- Use `ObservableProperty` e `RelayCommand` quando necessário
- Separe responsabilidades em serviços e repositórios
- Nomeie arquivos de acordo com o padrão MVVM
- Evite duplicação de código
- Adicione comentários somente quando o código não for autoexplicativo
- Teste suas alterações antes de enviar o PR

---

## 🧹 Convenções de commit

Use mensagens de commit claras e significativas. Exemplos:

- `feat: adicionar tela de detalhes do filme`
- `fix: corrigir bug na navegação entre telas`
- `refactor: remover código duplicado na ViewModel`
